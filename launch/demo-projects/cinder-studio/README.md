# Cinder Studio

Cinder Studio demonstrates a screenshot-led architecture and interiors website with original generated imagery, responsive editorial composition, project detail, services, studio philosophy, team, and contact flows.

## Stable routes

- `/launch-demo/cinder-studio`
- `/launch-demo/cinder-studio/project/stone-court`
- `/launch-demo/cinder-studio/contact`

Every route accepts `demoState=default|loading|error|empty|verified|mobile`. Add `demoControls=1` to reveal the fixture controller.

## Talking points

- All three architectural images were generated specifically for this launch demo and are stored locally.
- The design is original and is not a recreation of any specific architecture studio.
- The home page includes selected work, practice areas, philosophy, team, and contact direction.
- The project gallery and contact confirmation are interactive and keyboard accessible.
- Motion is deterministic, transform-only, and disabled for reduced-motion preferences.
